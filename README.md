# VoxPilot 🎙️

> A voice-first AI productivity and study assistant built to turn natural language into action.

VoxPilot is a modern productivity dashboard that allows users to manage tasks, organize study plans, track productivity, and interact with their tasks using voice commands.

The project was developed with a voice-first development workflow using **Wispr Flow** and **Cursor/VS Code**, demonstrating how voice-driven development can accelerate the creation of a real-world application.

---

## ✨ Features

### 📋 Smart Task Management
- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Set task priority
- Add due dates
- Organize tasks by category
- Search tasks
- Filter tasks by status and priority

### 🎙️ Voice Commands

VoxPilot supports natural voice commands such as:

```text
"Add a high priority task to finish my AI project tomorrow."

"Complete finish my AI project."

"Delete finish my AI project."
